# 辅助工具演示

## 目的

生成网格、轴、边界、相机和灯光辅助线几何体。

## 源码

`examples/helpers_demo.rs`

## 相关功能标志

默认外观

## 运行或检查

```sh
cargo run -p scenekit --example helpers_demo
```

## 查看内容

- 示例应使用列出的功能编译。
- CPU 示例不应需要 GPU 设置。
- 渲染器示例可能需要工作的原生图形后端或无头支持。
