# Hello Cube

## 目的

创建一个生成的立方体场景并通过渲染器渲染它。

## 源码

`examples/hello_cube.rs`

## 相关功能标志

renderer

## 运行或检查

```sh
cargo run -p scenekit --example hello_cube --features renderer
```

## 查看内容

- 示例应使用列出的功能编译。
- CPU 示例不应需要 GPU 设置。
- 渲染器示例可能需要工作的原生图形后端或无头支持。
