# 常见问题

## Scenix 是游戏引擎吗？

不是。Scenix 是一个模块化的场景、渲染、加载、动画桥接和浏览器集成工作区。它不提供 ECS、物理、音频或游戏循环所有权。

## 我需要渲染器吗？

不需要。CPU 创作、几何体生成、光线投射、辅助工具、材质、灯光、纹理和相机在没有 GPU 渲染的情况下很有用。

## 加载器将纹理上传到 GPU 吗？

不。加载器输出保持为 CPU 数据。显式向 `Renderer` 注册资产。

## Animato 默认包含吗？

不。当你需要桥接或剪辑运行时时启用 `animato`。Scenix v1.5.0 解析 Animato 1.7.0。

## 网站可以部署到静态托管吗？

可以。它是 Leptos CSR，使用 Trunk 为 GitHub Pages 在 `/scenekit/` 构建。
